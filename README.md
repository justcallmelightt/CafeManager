# CafeManager
> 2026학년도 미림마이스터고등학교 뉴미디어소프트웨어과 1학년 2학기 Java 수행평가 <br>
> Java와 Swing을 직접 활용하며 구현력과 이해도를 높이기 위한 학습·쇼케이스 프로젝트

CafeManager는 실용적인 상용 서비스를 목표로 하기보다, 지금까지 학습한 Java의 문법과 객체 지향 개념을 실제 프로그램 구조에 직접 적용하며 현재의 구현력을 확인하고, 개발 과정에서 Java에 대한 이해와 구현 능력을 높이기 위해 제작하는 학습·쇼케이스 프로젝트입니다.

프로젝트는 사전에 작성한 CafeManager 기획서를 기준으로 진행하며, 기능을 빠르게 완성하는 것보다 각 클래스의 역할을 명확하게 나누고 객체 간 데이터가 어떻게 전달되는지 직접 설계하며, 작성한 코드의 동작 원리와 사용 이유를 스스로 설명할 수 있는 상태를 중요하게 생각합니다.

주문, 결제, 재고, 매출, 관리자 기능처럼 서로 다른 책임을 여러 클래스로 분리하고, 상속과 객체 지향 구조를 적극적으로 활용하여 main 메소드에 모든 로직을 집중시키지 않는 방향으로 개발합니다.

또한 GUI의 완성도보다 핵심 로직을 먼저 구현하고 검증한 뒤 Swing을 연결하며, 데이터 저장 역시 외부 프레임워크보다 Java File I/O를 활용하여 가능한 한 Java 자체의 기능을 이해하고 직접 사용하는 것을 목표로 합니다.

개발 과정에서는 AI를 이용해 완성된 기능이나 프로그램을 한 번에 생성하는 바이브코딩 또는 AI 에이전트 방식을 절대 사용하지 않습니다. AI 챗봇은 Java 개념 학습, 구현 방향에 대한 조언, 코드 리뷰와 오류 분석 등을 위한 보조 수단으로만 활용하며, 실제 프로젝트에 포함되는 모든 코드는 작성 이유와 동작 과정, 사용된 개념을 직접 이해하고 설명할 수 있어야 한다는 원칙을 따릅니다.

## Development Principles

### 1. 직접 이해하고 구현한다
프로젝트에 포함되는 모든 코드는 작성 이유와 동작 과정을 직접 이해하고 설명할 수 있어야 합니다.
단순히 실행되는 코드를 만드는 것보다, 코드가 어떤 흐름으로 동작하는지 이해하는 것을 우선합니다.

### 2. 클래스의 책임을 적극적으로 분리한다
여러 기능을 하나의 클래스나 `main` 메소드에 집중시키지 않습니다.
메뉴, 주문, 결제, 재고, 매출, 데이터 저장 등 서로 다른 책임은 가능한 한 명확한 클래스로 분리하여 객체 간의 역할과 데이터 흐름이 드러나는 구조를 지향합니다.

### 3. 객체 지향 개념을 실제 구조에 적용한다
상속, 캡슐화 등 학습한 객체 지향 개념을 단순히 사용하기 위해 추가하지 않고,
실제로 코드의 중복을 줄이거나 책임을 명확하게 만들 수 있는 부분에 적용합니다.

### 4. 핵심 로직을 GUI보다 먼저 구현한다
Swing 화면부터 제작하지 않고 주문, 결제, 재고 관리 등의 핵심 로직을 먼저 구현하고 테스트합니다.
핵심 기능의 동작을 확인한 이후 GUI와 연결합니다.

### 5. 가능한 한 Java 자체의 기능을 활용한다
프로젝트의 목적이 Java 구현력 학습에 있는 만큼 불필요한 외부 프레임워크나 다른 언어에 의존하지 않습니다.
GUI는 Java Swing, 데이터 저장은 Java File I/O를 활용합니다.

### 6. 기획서를 구현의 기준으로 삼는다
사전에 작성한 CafeManager 기획서의 기능, 구조와 개발 계획을 기준으로 프로젝트를 진행합니다.
개발 과정에서 변경이 필요한 경우에도 기존 기획의 목적과 수행평가 기준을 벗어나지 않는지를 먼저 확인합니다.

### 7. 바이브코딩과 AI 에이전트를 사용하지 않는다
AI에게 요구사항만 전달하여 완성된 프로그램이나 기능 전체를 생성하는 바이브코딩 방식과,
AI가 프로젝트의 파일을 직접 읽고 수정하거나 여러 단계의 개발 작업을 대신 수행하는 AI 에이전트 기반 개발 방식을 사용하지 않습니다.

AI 챗봇은 개념 학습, 구현 방향 탐색, 코드 예제 참고, 코드 리뷰와 오류 분석 등을 위한 보조 수단으로만 활용합니다.
프로젝트에 포함되는 코드는 직접 확인하고 이해하며, 작성 이유와 동작 과정을 스스로 설명할 수 있어야 합니다.

### 8. 학습 수준에 맞춰 단계적으로 확장한다
아직 학습하지 않았거나 이해하지 못한 Java 기능을 단순히 완성도를 높이기 위해 무리하게 사용하지 않습니다.
새로운 개념이 필요한 경우 해당 개념을 먼저 학습하고 이해한 뒤 프로젝트에 적용하며,
기초적인 구현에서 시작해 학습 진도에 따라 프로그램의 구조와 기능을 단계적으로 확장합니다.

### 9. 구현 과정 자체를 학습 결과로 남긴다
완성된 프로그램만을 결과물로 보지 않습니다.
기능을 하나씩 구현하고 수정하며 Java에 대한 이해와 구현력이 어떻게 발전했는지를 프로젝트의 중요한 결과로 봅니다.

## Goal

기획서에서 계획한 CafeManager의 기능을 Java로 직접 구현하여 완성하는 동시에, 프로그램의 구조와 주요 코드, 객체 간 데이터 흐름을 스스로 이해하고 설명할 수 있는 수준의 Java 구현력을 갖추는 것을 최종 목표로 합니다.
