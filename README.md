# CafeManager
> 2026학년도 미림마이스터고등학교 뉴미디어소프트웨어과 1학년 2학기 Java 수행평가 <br>
> Java와 Swing으로 구현 역량을 보여주기 위한 프로젝트

CafeManager는 실용적인 상용 서비스를 목표로 하기보다, Java의 문법과 객체 지향 개념을 실제 프로그램 구조에 적용하고 그 구현 과정을 이해하기 위해 제작하는 학습·쇼케이스 프로젝트입니다.
기능을 빠르게 완성하는 것보다 각 클래스의 역할을 명확하게 나누고, 객체 간 데이터가 어떻게 전달되는지 직접 설계하며, 작성한 코드의 동작 원리를 설명할 수 있는 상태를 중요하게 생각합니다.
주문, 결제, 재고, 매출, 관리자 기능처럼 서로 다른 책임을 여러 클래스로 분리하고, 상속과 객체 지향 구조를 적극적으로 활용하여 main 메소드에 모든 로직을 집중시키지 않는 방향으로 개발합니다.
또한 GUI의 완성도보다 먼저 핵심 로직을 구현하고 검증한 뒤 Swing을 연결하며, 데이터 저장 역시 외부 프레임워크보다는 Java File I/O를 활용하여 가능한 한 Java 자체의 기능을 이해하고 사용하는 것을 목표로 합니다.
AI는 코드 생성 도구라기보다 학습과 검토를 돕는 보조 수단으로 사용하며, 프로젝트에 포함되는 모든 코드는 작성 이유와 동작 과정을 직접 설명할 수 있어야 한다는 원칙을 따릅니다.
